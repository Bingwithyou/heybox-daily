# Heybox Daily 在线托管网站

用户已批准登录、任务、赞助三页及多用户托管方案，选择直接公开登录。拟使用 `heybox.cansiny.top`。本次先完成可运行、可测试的实现；新建 Cloudflare 资源、绑定 DNS 和正式部署在结果可审阅后按明确授权执行。

## 用户流程

- 直接使用小黑盒手机号、短信验证码登录，不增加邮箱或 OAuth 注册步骤。以小黑盒真实返回且相互校验的盒友 ID 识别用户。
- 登录按钮明确说明会保存登录态并开启自动任务，提示可能导致手机 APP 退出登录。Better Auth 管理独立的网站会话，浏览网站不重复触发小黑盒登录。
- 我的任务展示四项任务、下次执行时间、最近记录与奖励变化。北京时间每天 00:01 开始排队执行；用户可暂停、恢复、手动补跑未完成项。
- 小黑盒登录失效后暂停执行并显示重新验证入口。账号菜单包含退出网站、重新验证和删除托管数据；退出网站不等同暂停任务。
- 赞助页仅保留简短说明、现有 `.github/sponsorship/sponsorship-cats.png` 原图和查看原图入口；不使用 AI 预览图里的重绘二维码。登录页及站内导航均可进入赞助页。
- 沿用批准的白底简洁 UI，使用表格和分隔线，不增加装饰、嵌套卡片或重复操作；兼容手机布局。

## 技术边界

- 采用用户《技术栈选型》的适用部分：TypeScript、React 19、TanStack Start/Router、Tailwind CSS v4、shadcn/ui base-nova、Lucide、oRPC、Better Auth、Cloudflare D1 + Drizzle、Workers + Wrangler、Vite+ 工具链及 pnpm workspace。版本实施时查询官方资料和 registry 后固定。
- 网站与 API 位于 Workers，账号、站内会话、加密凭据、任务和记录存 D1。静态赞助图随网站提供；没有文件上传或邮件需求，不引入无用存储和邮件功能。
- 现有 Oracle VPS 承担 Chromium 设备令牌初始化、原生 Java 签名和日常执行。网站通过受保护的服务接口调用登录执行端；执行端通过受保护的站内 API 领取任务、回传状态。服务认证凭据仅在服务器持有。
- 复用当前脚本和已经验证的协议；保留 CLI、已有 Docker 使用方式和 `v0.1.0` 行为。将交互登录拆为可组合的发码、验证函数，CLI 继续包装这些函数。
- 网站不执行阻塞式 Java 签名。VPS 的 HTTP 接入与实际任务运行分开，使用有超时、并发上限的子进程；账号凭据通过内存/标准输入传递，不放命令行或日志。

## 数据和安全约束

- 网站用户、小黑盒凭据、网站会话分别建模。每个盒友 ID 对应唯一网站用户，任何读取和操作均从当前站内会话取得所有者，不相信客户端提交的用户 ID。
- 小黑盒凭据使用 AES-GCM 加密，绑定账号和版本；主密钥单独保存在执行环境，不进仓库或数据库。返回浏览器的数据始终不含 `pkey`、设备令牌、密文或服务认证凭据。
- 登录挑战与浏览器会话绑定，有有效期和累计错误次数限制；发码与验码使用同一设备配置。手机号、验证码只用于本次流程；限流记录使用不可逆的键，不保存明文号码。
- 公开发码按手机号、IP 及全站容量限流；同一挑战不能重复消费或并发验证成功。校验来源、Cookie、CSRF 和输入长度，错误及日志脱敏。
- 重新验证成功后更新凭据版本，旧任务结果不能覆盖新凭据或错误地将新登录标成失效。失败不破坏原有可用凭据。
- 删除托管数据后取消未开始的任务、停止后续步骤并移除凭据及关联记录；已发送的外部请求不能撤回，运行状态应如实反映。

## 调度和失败处理

- Cloudflare 定时触发将到期用户加入持久任务表，按盒友账号与北京时间日期去重。VPS 领取任务时使用租约，并限制同账号并发。
- 重启、超时后允许重新领取。每次执行先查真实任务状态，跳过已完成项；不声称外部接口具有严格 exactly-once 保证。
- 短暂网络失败有限重试并退避；登录失效不自动重新发短信。跨日任务停止按旧日期更新结果，交给当天任务继续处理。
- 任务结束重新读取小黑盒状态，确认签到及分享结算；记录只包含用户可读结果、时间和奖励变化。

## 验收

- 现有 26 项测试和独立原生签名检查继续通过；登录协议及 CLI 用法保持兼容。
- 验证双用户隔离、验证码挑战绑定/过期/次数/重放、限流、凭据加密与轮换、暂停/删除、任务去重和租约恢复、旧凭据结果竞争、跨日及重试边界。
- 网站与执行端构建成功，D1 本地迁移和路由集成测试通过；浏览器验证三页、移动端、空状态和失效状态。赞助页引用文件需与原始图片哈希一致。
- 所有真实短信、真实账号及生产资源操作沿用具体授权；自动化测试使用模拟上游，不能误发短信或触发其他用户的任务。

## 回滚

网站、执行端和数据迁移独立发布；保留现有 CLI 镜像和配置。出现问题可停止网站调度和执行端，不影响原有 CLI 或 VPS 上其他服务。凭据密钥轮换需保留对应解密版本；数据库迁移先备份，不使用破坏性自动回滚。
