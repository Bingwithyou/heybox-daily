# 抽奖活动接入

## 已批准范围

2026-10-27 用户批准在网站接入抽奖活动，并要求先验证关注、参与和分享流程。

- 展示进行中的活动、当前账号资格、是否已参与、实际抽奖券数量。
- 关注是必要前置条件时显示“关注并参与”；用户点击后仅关注该活动要求的账号，回查前置任务完成后再参与。
- 拥有游戏类以小黑盒当前账号的资格结果为准，满足才允许参与；未满足显示所需游戏。未知前置条件不自动处理。
- 无前置条件可直接参与。已参与不重复报名，未完成分享可继续完成。
- 参与后自动完成分享任务并回查任务和抽奖券；不以 HTTP 成功代替任务成功。
- 不发送好友消息、不邀请助力、不发帖、不购买游戏、不自动取消关注，不自动参与未来活动。
- 已验证当前账号的 9351 分享任务从未完成变为完成，抽奖券 1100 → 1200。9351 对未参与者仍要求拥有《黑神话：悟空》，不能将已参与时省略的 front_task 解释为所有用户无门槛。

## 行为和边界

网站“我的任务”增加简洁活动列表，保持原页面布局，不改每日任务开关或定时流程。每项活动由用户显式点击。关注按钮列出涉及的账号；资格未知或读取失败时不开放参与。后台重新获取活动、资格与账号状态，关注目标只从实时活动协议解析，浏览器传递的已确认账号范围仅用于防止条件变化后误关注；奖励数和完成状态均以上游回查为准。列表读取无关注、参与、分享副作用。

使用现有加密凭据和 Runner 调用小黑盒。网站只返回精简活动视图，不暴露登录态、助力码、内部协议或原始响应。操作按账号串行，重复点击不会并发执行；每一步回查，失败保留已完成进度，下次只补未完成步骤。关注、报名超时后先回查，不直接重放写请求。
