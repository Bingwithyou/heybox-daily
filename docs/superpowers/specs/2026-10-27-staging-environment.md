# 预发布环境

用户已批准：增加独立预发布环境并部署，提供访问链接。用于验收当前 UI，不操作真实小黑盒账号。

## 环境与边界

- 网站为 Cloudflare Worker `heybox-daily-staging`，域名 `preview.heybox.cansiny.top`。
- 独立 D1 `heybox-daily-staging`、网站会话密钥、服务令牌、模拟凭据加密密钥，不复用正式环境数据或密钥。
- 在现有 VPS 的独立目录、Compose 项目和网络运行模拟 Runner，通过独立 Tunnel 暴露 `heybox-preview-runner.cansiny.top`。现有正式 Runner 和 Tunnel 不修改。
- 禁用预发布 Cron。登录、重试等操作仍走真实网站 API，模拟 Runner 仅收到通知时领取测试任务并生成模拟结果。
- 模拟 Runner 只接受公开演示号码和固定演示验证码，拒绝其他号码；活动列表和参与结果来自内置测试数据，不调用小黑盒。
- 登录页显示演示号码与验证码，顶部显示预发布标识。全站禁止搜索收录。
- 演示历史覆盖已完成、已跳过、失败和旧记录收益未知；活动覆盖可参与、需要关注、资格不足、已参与。

## 压力测试结论（grill-with-docs）

- Vite 插件必须在构建时通过 CLOUDFLARE_ENV 选择环境；额外使用 staging mode 控制演示提示，发布前核对输出 Worker、域名、D1 和 Cron，防止误发正式环境。
- Wrangler 的路由和定时配置可能继承，预发布显式覆盖；绑定与 vars 显式定义。构建时隔离本地 .dev.vars，密钥仅通过 Secret 设置。
- 模拟 Runner 的程序入口与正式入口分离，拒绝正式网站回调地址，凭据使用独立密钥；真实任务执行函数不参与模拟路径。
- 演示账号是公开测试数据，多个访问者可能共享其操作状态。模拟活动状态在 Runner 重启后重置；数据库中的历史记录保留，供 UI 验收。
- SSL、DNS、Tunnel 连接及公网请求需要部署后实测；只创建明确命名的新增资源，保留正式资源状态作为核对基线。
- 此环境不能作为真实小黑盒登录、限流或实际发奖的验收结论。未发现需要改变已批准方案的重大决策。

## 验收

访问固定 HTTPS 链接；使用演示账号登录，能查看最新 UI、历史、收益图标、活动，模拟参与后券数更新。生产环境配置与运行资源不变。部署脚本可再次手动发布；不增加自动部署，不 commit/push。
