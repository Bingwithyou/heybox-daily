# 多账号与接入数量

用户已批准 UI 预览及以下行为，仅本地实现与验证，不提交、推送或部署。

- 全站页脚显示「已接入 X 个账号」，登录前后及赞助页一致。按现存 hosting 的唯一盒友 ID 计数，暂停、凭据失效仍计入，删除扣除；公开接口仅返回总数，最多缓存 5 分钟。
- 同一浏览器最多保存 5 个不同账号的有效网站会话。账号菜单列出昵称、盒友 ID、当前选中项，支持添加与切换。切换不改变任何账号的自动任务设置，换浏览器须分别登录。
- 「重新验证」账号入口改为「重新登录」，复用短信及人机验证流程，绑定目标账号，账号不符时拒绝更新。成功后重新开启任务并补跑未完成项，失败不破坏已有数据。
- 「退出登录」先确认，暂停当前账号任务并撤销该账号在本浏览器的会话，保留托管凭据和记录；其他账号不受影响。剩余有效账号可继续切换，否则进入登录页。已发送上游请求无法撤回。
- 删除托管数据只作用于当前账号，删除其所有网站会话、凭据及任务记录，其他账号不受影响。
- 暂停、补跑、退出及删除均校验页面展示的账号与当前会话一致；旧标签页发现账号变化后要求刷新，不能误操作新账号。
- PC 顶部展示 GitHub 仓库图标，PC 页脚不重复；手机保留页脚仓库链接。保留现有平面布局及白底风格，不增加统计卡片。

## 实现约束

复用 Better Auth 会话及 multi-session 的签名 Cookie 模式；网站用户与盒友 ID 一一对应，无主账号绑定关系，无数据迁移。所有账号访问必须来自已验证的 HttpOnly Cookie 与数据库有效会话，不接受仅凭客户端账号 ID 授权。重新登录的目标与短信挑战绑定且有过期校验。保护现有未提交的登录冷却、设备令牌等改动。

## 验收与回滚

本地模拟上游验证多账号隔离、5 账号限制、同账号去重、退出暂停与租约停止、删除范围、过期会话、重新登录目标不符、旧页面提交拒绝，以及计数口径。检查 PC 和手机布局，执行 web 单元测试、集成测试、类型检查、lint 和构建。无真实短信和生产写入。回滚仅撤销本次补丁；无数据库迁移，已暂停账号保持暂停，重新登录可恢复。
