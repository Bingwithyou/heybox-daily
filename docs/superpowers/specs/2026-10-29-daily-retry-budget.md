# 每日执行预算

用户已批准：每个托管账号每天最多执行 5 次（包含首次），不跨北京时间日期；验证后部署正式环境，并评估 D1 与 Cloudflare 用量。

- 普通临时失败依次延后 5、20、60 分钟，此后每次 2 小时；限流依次 15、30、60 分钟，此后 2 小时，等待时间不得短于 Retry-After。保留 0–60 秒抖动。
- 达到 5 次或跨日即停止。完成、凭据失效、人工验证及明确协议错误提前停止。
- 每次实际领取计数；消息重复投递、手动重新排队、重新登录、暂停恢复不能重置当日次数。次日新任务使用新预算。
- 租约失效按同样预算和普通退避恢复；历史尝试记录保留。
- 继续使用 D1 的 available_at 和现有队列，等待不占并发，实际并发仍为 8。
- 页面运行中和到期排队时每 5 秒刷新；未来延后任务每 60 秒刷新。
- 部署后检查今日符合条件的旧临时失败；仅在剩余预算内恢复。正常已完成账号不重跑。

沿用已有数据库结构和 30 天清理，不新增资源或迁移，不执行 Git 提交或推送。
