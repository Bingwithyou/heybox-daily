# TypeScript 命令行迁移

用户已确认：业务代码采用 TypeScript + pnpm，保留 Docker 内部的 Java/Unidbg，暂不增加网页。

## 范围与行为

- 将 `src/*.js` 迁移为启用严格检查的 `src/*.ts`，保留现有本地签名、接口参数、状态判断和日志。
- 使用 TypeScript 编译到 `dist/`，运行时仍为 Node.js 24；`check` 只查询，`run` 只处理已批准的签到和三项分享任务。
- pnpm 版本及开发依赖固定到当前稳定版本，使用 `pnpm-lock.yaml`；Docker 和 CI 采用同一套安装、类型检查、构建和测试命令。
- Java 签名器和目前的私有资源、配置格式保持兼容，现有 Python 导入及资源提取工具本轮保留。
- 保留本地已完成的 README 风格、使用文档和赞助图片调整。

APK 精简与扫码/验证码登录本轮仅调查、回答验证方式，不把未验证的初始化流程写成已实现功能。网页登录成功不能证明原生签到可用。

## 验收

严格类型检查与编译成功；原有 15 项回归测试验证编译后的代码；Docker 成功构建，并能读取真实账号状态、跳过当天已完成任务。所有凭据及 APP 资源继续留在忽略目录。

## 发布与回滚

本轮不增加网页、远程资源或定时任务，不自动提交、推送或部署。回滚仅恢复本次语言和构建配置变更，保留之前的文档调整及 `private/`、`state/`、`.research/`。
