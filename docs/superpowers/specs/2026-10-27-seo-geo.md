后续用户修正（优先于下文初版）：默认入口 `/` 对未登录用户进入 `/login`，已登录用户进入 `/tasks`。公开介绍移到 `/about`，仍可由页脚访问并列入 sitemap。直接请求和站内导航进入 `/tasks` 都必须先验证登录态；访客、无效或已撤销会话重定向登录，不先挂载任务页面，也不依赖任务接口报错来判断登录。未配置认证的本地预览同样正常展示登录页。

## 行为

- `/` 是服务端渲染的公开首页：产品用途、签到和三项分享任务、在线登录及自部署入口。保持现有简洁样式。
- 原任务界面迁移到 `/tasks`；登录、切换账号及退出后仍有账号时进入该地址。未登录访问任务仍走原认证流程。
- `/help`、`/privacy` 提供可链接、服务端渲染的使用和隐私说明，替代说明弹窗。常见问题采用可展开正文，服务器 HTML 中保留答案。
- 公开页面拥有独立标题、描述、canonical、Open Graph / Twitter 元数据；首页提供 WebSite / SoftwareApplication JSON-LD，内容与可见正文一致。
- `/robots.txt` 允许搜索抓取公开内容，排除接口；`/sitemap.xml` 仅列公开可收录页面。登录、任务和错误页面以及接口通过 noindex 防止收录，不将 robots 当鉴权。
- 不承诺搜索排名或 AI 引用。不增加伪造评价、关键词堆砌或特殊 AI 专用正文。

## 约束及验收

保留现有性能优化、账户和任务数据合同；不修改数据库。爬虫和普通访客得到相同公开正文；公开页不能依赖账号接口成功。站点绝对 URL 统一使用部署网站 https://heybox.cansiny.top。

验证无 JavaScript 的 HTTP 页面包含正文、唯一标题和 canonical、有效 JSON-LD；检查登录和任务 noindex、404 状态、sitemap、robots 及多账号流程。执行 Web 测试、构建、类型检查、lint、格式检查和隔离集成测试；浏览器检查桌面和移动端。
