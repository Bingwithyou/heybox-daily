# 在线托管网站实施计划

依据已批准的 `docs/superpowers/specs/2026-10-27-hosted-website.md` 执行。公开登录已确认。UI 已生成并获准，赞助图使用仓库原图。

## 1. 工程与共享协议

- 在现有仓库增加 `apps/web/`、`apps/runner/`、必要的共享协议包和 `pnpm-workspace.yaml`；保留根目录现有 CLI。
- 查询并固定框架/依赖版本，配置 Workers 构建、TypeScript、Vite+、Tailwind/shadcn base-nova 和 oRPC。浏览器与 Workers 不能引入原生 Java 或 Node-only 模块。
- 定义登录挑战、公开用户状态、任务状态、执行端请求/响应和标准错误合同；不在公开 DTO 暴露凭据。
- 验证：依赖安装、类型检查、最小 SSR/路由构建及现有 CLI baseline。

## 2. 复用登录与执行核心

- 调整 `src/login.ts`，抽取发码与验证码验证能力，保持 `runSmsLogin` 及原有测试覆盖。
- 在 `apps/runner/` 实现受保护的登录接口、短期挑战、加密凭据和有界子进程执行；后台轮询任务并回传结果。
- 测试先覆盖同一挑战多次验证、失败不覆盖原配置、挑战过期与绑定、接口认证、进程超时和无凭据日志，再实现对应行为。
- 验证：根项目 `pnpm test`、runner 测试及真实原生离线 smoke；不用测试触发实际短信。

## 3. D1、身份和调度

- 在 `apps/web/` 增加 Drizzle schema、D1 SQL migration、Better Auth 小黑盒自定义登录入口、oRPC 服务和 Workers 定时处理。
- 实现受保护的 worker 领取/回传接口、账号所有权验证、限流、加密凭据保存、去重/租约/退避、暂停/恢复/删除和登录失效处理。
- 使用本地 D1 和模拟执行端验证双用户越权、并发登录、旧版本回传、重复调度、租约到期、跨日、限流和删除后不再执行。
- 验证：迁移仅对本地数据库运行；站点类型检查、服务测试及生产构建通过。

## 4. 三页 UI

- 登录页：手机号、验证码、明确的登录并开启任务操作及必要提示；支持真实加载、冷却和失败状态。
- 任务页：四项任务、自动任务开关、下次执行、按需补跑、历史和账号菜单；仅展示当前用户数据。
- 赞助页：复制仓库原图到静态资源目录并校验哈希，保留原图链接；公共导航统一。
- 使用当前已生成图片作为布局参考，不把生成的 UI 栅格图作为网页主体。无 mock 数据伪装真实运行结果。
- 验证：浏览器桌面和手机布局、键盘操作、登录失败/过期/空记录/暂停/删除确认、赞助图显示与原图一致。

## 5. 集成、文档与交付

- 增加独立网站/runner 容器与部署配置、环境变量示例、D1 迁移命令及维护说明；不能覆盖现有 VPS 服务或用户配置。
- CI 增加站点与 runner 的类型检查、关键测试和构建，保留既有 CLI 镜像和原生离线验证。
- 验证一条模拟用户从登录到定时执行、回读与暂停/删除的端到端链路，检查仓库不包含密钥或真实账号数据。
- 完成本地实现与可审阅预览后，再按授权进行 Cloudflare 注册/DNS/部署和真实账号验收；未获授权的生产操作保持待执行。
