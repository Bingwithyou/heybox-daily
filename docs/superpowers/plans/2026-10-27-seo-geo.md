## 边界与回滚

- 风险：任务地址变化时漏改登录或切换跳转；继承根元数据造成 canonical 或 noindex 错误；公开页面加载时意外带入私人任务数据。通过 HTTP、浏览器及已有账号集成测试覆盖。
- 当前工作区有其他性能改动；只修改必要位置并保留其行为。回滚时仅撤回本次新增文件、路由移动和导航 / SEO 修改，不整体重置文件。
- 无数据库迁移或外部写入；发布需另行授权。

## 后续入口修正

用户要求访客默认进入登录页，且不允许未登录用户进入任务页。将公开介绍移至 `/about` 并调整 canonical、JSON-LD 和 sitemap；`/` 作为会话入口。Worker 使用现有 Better Auth 会话检查，在返回任务 HTML 前重定向访客；任务路由的 beforeLoad 检查站内导航，阻止任务组件挂载及数据请求。保留任务运行期间会话失效时的跳转。介绍页仅对已登录用户显示任务入口。

先增加 HTTP 回归断言，旧版本在访客访问 `/` 返回 200 而非 302 时失败。覆盖 `/`、`/tasks`、尾斜杠和查询参数、无效 Cookie、已登录入口和撤销会话；本地未配置认证时也检查跳转。重新执行 Web 构建、类型检查、lint、格式检查、单测和隔离集成测试，并在浏览器检查访客直接访问及站内进入任务页。

修正后上述检查全部通过。浏览器在未配置 API 的本地预览中，从 `/help` 点击任务链接直接返回 `/login`；网络记录只有账号检查，没有 `/rpc/dashboard` 请求。默认入口和直接任务 URL 都返回 302，介绍页仍返回可抓取正文。开发服务继续保留在 `http://127.0.0.1:3000/`。
